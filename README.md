
# Recommendation System

Register Number: 24MIS0492

## Version 1 — Show List

A Flask web application that displays recommended items
with their category, rating, and price.

## Features
- Display all available items
- Health-check endpoint at /api/health

## Run locally

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

Open http://localhost:5000
